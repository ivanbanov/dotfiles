# Claude Instructions

- **Use GitHub CLI** (`gh`) for any GitHub operations (PRs, issues, repos)
- **Use Atlassian acli** for Jira/Confluence operations
- **Never commit or push** unless explicitly asked — you can propose and wait for approval
- **Use Slack MCP** when asked to do something on Slack
- **Never send Slack messages** without being asked first
- **Use ASD-STE-100 when you speak to the operator.**
